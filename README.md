# 支付欺诈防控：出海团队实战指南

（暂定书名，写作中）

越来越多的国内团队在做海外业务，只要面向海外用户收款，就要面对国际卡组织的规则、发卡行的风控和攻击者的试探。本书想把海外卡支付欺诈防控这件事讲完整：一笔卡支付是怎么跑完的，攻击者从哪里下手，认证和卡组织规则能挡住什么，商户自己的风控体系该怎么搭，出了问题怎么应对。

## 读者

1. 做海外业务的产品、技术、风控和运营团队。
2. 负责支付接入、订阅计费和收款通道的工程师。
3. 想系统了解卡支付风险的创业者和管理者。

本书讨论国际卡组织的卡在海外线上支付中的风险，不讨论中国大陆境内发行的银行卡在国内的线上支付。
